## คืออะไร?

CubeFace Studio เป็นโปรแกรมบนเครื่อง (Windows, สร้างด้วย Electron) สำหรับวาดสกิน Minecraft
แล้วทำเป็น avatar ของ **[Figura](https://figuramc.org)**: สกินที่หันหัวแบบนุ่มนวล ผมแกว่งได้
กระพริบตา เปลี่ยนสีหน้า เรืองแสงในที่มืด และมีวงล้อ action ไว้ควบคุมในเกม ทำงาน **ออฟไลน์**
ไม่มีการอัปโหลดอะไรออกไป

ตัวโปรแกรมมี **ภาษาไทยและอังกฤษ** (เปลี่ยนได้ตลอดที่ ⚙ ตั้งค่า)

## ความสามารถ

**วาดสกิน**
- วาดบนโมเดล 3D หรือหน้า UV แบบแบน สกินขนาด 64×64 ถึง 2048×2048 แขนแบบ Wide หรือ Slim
- แปรง (ปกติ หรือสมูทที่สีผสมกัน) ยางลบ ถังสี ไล่สี เลือกพื้นที่ (คัดลอก/ตัด/ย้าย/วาง) ดูดสี
  (กด Alt ค้าง) วาดสองข้างพร้อมกัน กันมือสั่น และวงกลมบอกตำแหน่งแปรง
- เลเยอร์ปรับความทึบ ล็อก รวม และตั้ง "เรืองแสงในที่มืด" ทีละเลเยอร์
- Palette สี (สร้างจากรูปได้) ตู้เสื้อผ้า ย้อนกลับ/ทำซ้ำ

**สร้าง Figura avatar**
- หัวสมูท (หมุนชิ้นที่ติดหัวของ avatar ที่รวมเข้ามาด้วย) แผ่นผมมีฟิสิกส์ กระพริบตา ปากขยับ
  ตอนพูด (Plasmo Voice) สีหน้าสำเร็จรูปและสีหน้าที่สร้างเอง
- เฟรมหน้า 16×16 ถึง 128×128 px วาดในหน้าต่างวาดหน้าโดยเฉพาะ บันทึกเป็นชุดหน้าตาไว้ใช้กับสกินอื่นได้
- เรืองแสง: ตา (ระบายเองได้ว่าจุดไหนเรืองแสง) แผ่นผม เลเยอร์ แต่ละส่วนมีสวิตช์ของตัวเอง
- ตั้งค่าวงล้อ action: วงล้อ Figura หรือวงล้อ Auria แบบมีแอนิเมชัน หลายหน้า ปุ่มย้อนกลับ /
  ถัดไป / หน้าแรก สวิตช์ตั้งค่าเริ่มต้นเปิดหรือปิดได้ ไอคอนเป็นไอเทม รูปภาพ หรือหน้าตา
- ส่งออกเป็นโฟลเดอร์หรือ `.zip` ไฟล์เดียว รวม avatar จากคลังเป็นตัวเดียว (แก้ชื่อไฟล์และสคริปต์
  ให้ทำงานต่อได้) ตัวเลือกสคริปต์แบบตัวช่วยของ Figura (ซ่อนเกราะ ผ้าคลุม Elytra ใส่ event ว่าง)
  และโลโก้ avatar
- ตัววัดขนาดไฟล์ที่วัดแบบเดียวกับ Figura (เทียบกับ avatar จริงแล้วคลาดไม่ถึง 0.1%)

**อื่นๆ**
- ส่งออก `.mcpack` สำหรับ Bedrock Edition
- โหมดโพส: ท่าสำเร็จรูป ท่าของตัวเอง ส่งออก Emotecraft `.json` บันทึกภาพ PNG พื้นหลังโปร่งใส
- คลัง Figura avatar (โฟลเดอร์ `.zip` `.rar`) และ Emote พร้อมสิทธิ์การใช้งาน
  (ฟรี / ซื้อมา / ของตัวเอง / สิทธิ์ขาด, เชิงพาณิชย์ แจกต่อ แก้ไข)

## วิธีใช้งาน

**[คู่มือการใช้งาน](docs/manual.th.md)** อธิบายทุกอย่างทีละขั้นพร้อมภาพ
([English manual](docs/manual.en.md)) ในโปรแกรมกดปุ่ม **คู่มือ** ที่หน้าแรกก็เปิดได้

สรุปสั้นๆ
1. กด **สร้างสกินใหม่** หรือ **นำเข้า PNG** ที่หน้าแรก
2. วาดสกิน เพิ่มแผ่นผมได้ในแท็บสกิน
3. ในแท็บ **Figura** วางกรอบตาและปาก กด **สร้างเฟรมหน้าอัตโนมัติ** แล้วตั้งค่าหัว ผม การกระพริบ
   และวงล้อ action
4. **ส่งออก… → Figura avatar** แล้ววางโฟลเดอร์หรือไฟล์ `.zip` ไว้ใน
   `.minecraft/figura/avatars/` แล้วเลือกในตู้เสื้อผ้าของ Figura

## ดาวน์โหลด

โหลดเวอร์ชันล่าสุดได้ที่ **[Releases](https://github.com/Maskbuild/Nkw-Custom-Skin/releases/latest)** (Windows 10/11, 64-bit)

- **CubeFace-Studio-Setup-1.0.0.exe**: ตัวติดตั้ง (เลือกโฟลเดอร์ได้ สร้างทางลัดใน Start menu และหน้าจอ)
- **CubeFace-Studio-1.0.0-win-x64-portable.zip**: ไม่ต้องติดตั้ง แตกไฟล์ไว้ที่ไหนก็ได้แล้วเปิด `CubeFace Studio.exe`

โปรแกรมยังไม่ได้เซ็นรับรอง (code signing) ครั้งแรก Windows SmartScreen อาจเตือน ให้กด *More info (ข้อมูลเพิ่มเติม) → Run anyway (เรียกใช้)*

## สร้างจากซอร์สโค้ด

ต้องมี **[Node.js](https://nodejs.org) 22 LTS ขึ้นไป** และ **Git**

```bash
git clone https://github.com/Maskbuild/Nkw-Custom-Skin.git
cd Nkw-Custom-Skin
npm install
```

| คำสั่ง | ใช้ทำอะไร |
| --- | --- |
| `npm run dev` | เปิดโปรแกรมแบบนักพัฒนา |
| `npm run build` | build โปรแกรมไว้ใน `out/` |
| `npm run dist` | สร้างตัวติดตั้ง Windows ไว้ใน `dist/` |
| `npm test` | รันเทสต์ทั้งหมด (vitest) |
| `npm run typecheck` | ตรวจ type ของ TypeScript |
| `npm run dev:web` | เปิดหน้าแก้ไขในเบราว์เซอร์ (เข้าถึงไฟล์ไม่ได้ ใช้ทดลอง UI เร็วๆ) |
| `npm run logo` | วาดไฟล์โลโก้/ไอคอนใหม่จาก `scripts/make-logo.cjs` |

สกินและคลังต่างๆ เก็บอยู่ที่ `%APPDATA%\nkw-skin-figura`

## โครงสร้างโปรเจกต์

- **Electron** + **React** + **TypeScript** รวมไฟล์ด้วย **electron-vite** 3D ใช้ **three.js**
  state ใช้ **zustand** แปลภาษาใช้ **i18next**
- `src/main`: ฝั่งเครื่อง (ไฟล์ คลัง avatar นำเข้า zip / rar ส่งออก)
- `src/preload`: ตัวเชื่อมระหว่างหน้าต่างกับฝั่งเครื่อง
- `src/renderer/src`: ตัวโปรแกรม
  - `skin/`: เอกสารสกิน เลเยอร์ พิกเซล ผม ตั้งค่า Figura
  - `figura/`: สร้าง Figura avatar (โมเดล Blockbench, `script.lua`, texture atlas, ขนาดไฟล์)
  - `bedrock/`, `pose/`: แพ็ก Bedrock และส่งออกท่า/อีโมต
  - `ui/`, `three/`, `i18n/`: หน้าจอ มุมมอง 3D ข้อความไทยและอังกฤษ
- `src/figura/`: สคริปต์ Lua ที่ใส่ไปกับ avatar (ฟิสิกส์ผม วงล้อ Auria)
- `tests/`: เทสต์ทั่วไป และเทสต์ที่รันสคริปต์ของ avatar จริงใน Lua VM กับ Figura API จำลอง
  (`tests/lua/figura_mock.lua`) กดทุกปุ่มในวงล้อ กับการตั้งค่าหลายแบบ
- `docs/`: คู่มือและภาพประกอบ · `build/`: ไอคอนโปรแกรม
